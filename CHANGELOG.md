# Changelog

## 1.0.0

The first public release, separated from the project-management application it grew out of.

- Image zoom (zoom steps, fit to width or height) remembered per chart.
- Gantt timeline zoom with a 7-week default and day, week and month ticks that change with the zoom.
- Export as PNG, SVG (with the chart's name above it) and CSV.
- Click events for boxes, cards, tasks, tree rows and groups on every chart type.
- Six chart types from one data model, each drawable as any other ("view as").
- Tree view with folders, highlights, descriptions and icons.
- Gantt chart with dependencies and arrows, tasks stacked beneath what they follow, unknown start and end dates, milestones, vertical markers, configurable colours, excluded days and more.
- A demo site that keeps charts in the browser's local storage, and documentation.
